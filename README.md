# Paper Sums 🦉

A warm, paper-cut-out style three.js game that teaches children **column addition** — a single static page.

- **Drag** paper digits from the tray into the answer boxes, starting with the **ones** column on the right.
- **Carry**: when a column makes 10 or more, the ones go in the box and the **1** is carried to the top of the next column.
- **Hints**: Pip the owl explains each step (read aloud, toggle with 🗣️), a sticky note shows each column's sum, and the counting frame (two ten-frames) fills with dots to show where "a ten" comes from.
- **💡 Help**: first press counts the dots; second press makes the right digit glow.
- **Levels**: 🐣 Easy (no carrying) · 🎒 Carry · 🚀 Big (3-digit) · ✏️ Make your own sum.

Play it: open `index.html` in a browser (needs internet for the three.js CDN and font), or visit the GitHub Pages site.
